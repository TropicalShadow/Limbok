# Limbok

> Limbok is a simple and lightweight Minecraft server software


## Features
- [x] Version Support
  - [x] 1.21.1
- [x] Proxy Support
  - [x] BungeeCord
  - [x] Velocity
- [x] Void Respawn
- [x] World Loading

## Installation
1. Download the latest version from the [releases page](https://github.com/TropicalShadow/Limbok/releases)
2. Run the server with `java -jar limbok.jar`
3. Edit the `server.properties` file to your liking
4. Run the server again

## Building
1. Clone the repository
2. Run `./gradlew shadowJar` to build the project
3. The jar file will be located in `build/libs`
